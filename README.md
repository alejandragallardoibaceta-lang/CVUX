# CVUX

Repositorio inicial de CVUX, preparado para continuar el desarrollo en un entorno
en la nube.

## Entorno de desarrollo

El repositorio está disponible en `/workspace/CVUX`. Git, Node.js, npm y Python 3
están disponibles en el entorno actual.

Para comenzar una sesión de trabajo:

```sh
cd /workspace/CVUX
git status
```

Cada tarea en la nube ya utiliza un entorno aislado. Utiliza este checkout; no es
necesario crear otro clon ni un Git worktree.

## Estado del proyecto

Esta base contiene únicamente la documentación inicial. Todavía no hay una
aplicación, dependencias, servicios o pruebas que instalar o ejecutar. Las
instrucciones de instalación y arranque se añadirán cuando se incorpore el código
del proyecto.
